# Sprite Sheets транспорту

Покладіть сюди по одному PNG на кожен вид транспорту:

- `metro.png`
- `tram.png`
- `trolleybus.png`
- `bus.png`

Кожен файл — це сітка кадрів одного виду транспорту під різними кутами
(типово 8 напрямків: N, NE, E, SE, S, SW, W, NW), розкладена по рядку(ах)
зліва направо, зверху вниз.

Після додавання файлу перевірте/поправте його параметри у
`src/config/transportSprites.ts`:

| Поле | Що це |
|---|---|
| `frameWidth` / `frameHeight` | розмір ОДНОГО кадру в пікселях у файлі |
| `columns` | скільки кадрів у рядку листа |
| `directions` | скільки всього напрямкових кадрів (напр. 8) |
| `rotationMode` | `'frames'` — кадри під кутами (типово); `'continuous'` — один кадр згори, обертається CSS |
| `baseHeadingDeg` | куди "дивиться" кадр №0 / єдиний кадр (0 = північ) |
| `displaySize` | розмір на карті в CSS-пікселях |

Поки файл відсутній — застосунок автоматично показує акуратний
геометричний маркер-фолбек, карта лишається повністю робочою.

Номер маршруту та кінцева зупинка НЕ повинні бути намальовані на самому
спрайті — вони рендеряться окремо компонентом `<RouteDisplay />` поверх
транспорту.
