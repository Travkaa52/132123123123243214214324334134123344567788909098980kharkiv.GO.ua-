# Налаштування Telegram-бота і Mini App

Постійного сервера немає, але для роботи підтримки й оголошень про
затримку (див. `INTEGRATION_NOTES_UK.md`) токен бота ПОТРІБЕН — його
використовує `.github/workflows/telegram-bot.yml` (або опційно
`bot/telegram_bot.py`), щоб забирати повідомлення й відповідати. Сам Mini
App (карта, маршрути, профіль) дійсно повністю без бекенду.

## 1. Створити бота

1. Відкрити [@BotFather](https://t.me/BotFather) у Telegram.
2. `/newbot` → вказати назву (наприклад, "Kharkiv GO") і унікальний username
   (має закінчуватись на `bot`, наприклад `kharkivgo_bot`).
3. BotFather видасть токен — **збережіть його**: він потрібен у секреті
   `BOT_TOKEN` (Settings → Secrets and variables → Actions), щоб
   спрацювала підтримка й оголошення про затримки. Детальніше — у
   `INTEGRATION_NOTES_UK.md`.

## 2. Підключити Mini App

1. У BotFather: `/newapp` → вибрати щойно створеного бота.
2. Назва застосунку, короткий опис, іконка (512×512 — можна взяти
   `frontend/public/icons/icon-512.png`).
3. **Web App URL** — посилання на ваш GitHub Pages сайт, наприклад:
   ```
   https://<ваш-username>.github.io/<назва-репозиторію>/
   ```
   (той самий шлях, що збирає `.github/workflows/deploy.yml`).
4. Готово — тепер `/newapp` дав посилання виду `t.me/kharkivgo_bot/app`.
   Це посилання вже відкриває застосунок як Mini App, з доступом до
   `Telegram.WebApp` API (профіль користувача підтягується автоматично).

## 3. Кнопка Menu Button (щоб застосунок відкривався по кнопці в чаті)

1. У BotFather: `/mybots` → обрати бота → `Bot Settings` → `Menu Button`.
2. `Configure menu button` → вставити той самий Web App URL.
3. `Edit menu button name` → наприклад "🚋 Відкрити карту".

Тепер у чаті з ботом внизу зʼявиться кнопка, яка відкриває Mini App.

## 4. Команда /start і обробка повідомлень

`/start`, звернення в підтримку і скарги на затримку вже обробляються
автоматично — `.github/workflows/telegram-bot.yml` (раз на ~5 хв, без
серверів) або опційно `bot/telegram_bot.py` (постійний процес, миттєво).
Деталі всієї схеми — в `INTEGRATION_NOTES_UK.md`, налаштування секретів —
там же.

Додатково можна ще налаштувати в BotFather **статичний** опис через
`/setdescription` і `/setabouttext` — просто текст, який бот показує до
першого повідомлення.

## 5. Перевірка


Відкрийте `t.me/<ваш_бот>/app` у мобільному Telegram (Mini App у десктоп-
клієнті теж працює, але зручніше тестувати на телефоні) — маєте побачити
застосунок з картою, і на вкладці "Профіль" — своє імʼя та фото з Telegram.
