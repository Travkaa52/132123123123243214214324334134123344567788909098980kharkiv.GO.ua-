# Kharkiv GO

PWA + Telegram Mini App громадського транспорту Харкова: карта, маршрути,
зупинки, обране та історія пошуку. Працює **повністю без бекенду** —
статичний фронтенд на GitHub Pages, профіль користувача підтягується з
Telegram.

## Архітектура

```
kharkiv-go/
├── frontend/           # React 19 + TypeScript + Vite + Tailwind + MapLibre GL
│   ├── src/data/         # зупинки/маршрути Харкова — статичний JSON, без БД
│   ├── scripts/          # process-telegram-bot.mjs, parse-telegram-channels.mjs
│   ├── data-runtime/     # технічний стан бота (не публічний)
│   └── public/data/      # route-alerts.json, notifications.json — публічні фіди
├── bot/                 # опційний Python-бот (постійний процес замість Actions-cron)
├── .github/workflows/   # автодеплой на GitHub Pages + обробка Telegram-апдейтів
├── BOT_SETUP.md          # як підключити Telegram-бота і Mini App
└── INTEGRATION_NOTES_UK.md  # повна схема бота підтримки й оголошень про затримки
```

Немає постійного сервера для самого застосунку (карта, маршрути, зупинки,
пошук, обране, історія, профіль — усе статично на GitHub Pages, дані
Харкова без відкритого GTFS-realtime фіда однаково не дали б "живих"
координат). Підтримка й оголошення про затримки транспорту працюють через
Telegram-бота — детально в `INTEGRATION_NOTES_UK.md`.

## Запуск локально

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Відкриється на `http://localhost:5173`. Для перевірки Telegram-інтеграції
(профіль, тема) застосунок треба відкрити саме через Telegram Mini App —
див. `BOT_SETUP.md`. Поза Telegram застосунок теж повністю працює, просто
без профілю (буде запропоновано "Відкрити в Telegram").

## Деплой на GitHub Pages

1. Запуште репозиторій на GitHub.
2. У налаштуваннях репозиторію: **Settings → Pages → Source → GitHub Actions**.
3. Запуште у гілку `main` (або запустіть workflow вручну: **Actions →
   Deploy to GitHub Pages → Run workflow**).
4. Workflow (`.github/workflows/deploy.yml`) сам збере фронтенд з правильним
   base path (`/<назва-репозиторію>/`) і задеплоїть у GitHub Pages.
5. Сайт зʼявиться на `https://<username>.github.io/<репозиторій>/`.

Якщо репозиторій називається `<username>.github.io` (кореневий user-сайт,
без підпапки) — приберіть `BASE_PATH` у workflow або задайте `BASE_PATH=/`.

## Telegram-бот і Mini App

Повна покрокова інструкція — у [`BOT_SETUP.md`](./BOT_SETUP.md): створення
бота через BotFather, підключення Mini App до URL з GitHub Pages, кнопка
Menu Button. Жодного серверного коду для бота не потрібно.

## Дані зупинок і маршрутів

`frontend/src/data/stops.json` і `routes.json` — стартовий набір із
кількох реальних локацій Харкова (Площа Свободи, Держпром, Південний
вокзал, метро М1 тощо) для демонстрації. Координати приблизні — перед
продакшн-релізом варто замінити/доповнити повним переліком через:

- ручний імпорт з відкритих даних міста (`opendata.kharkivrada.gov.ua`);
- або GTFS-експорт, якщо колись зʼявиться офіційний.

Формат — простий масив обʼєктів (`Stop[]` / `TransportRoute[]`, типи в
`src/types/transport.ts`), додавати нові зупинки/маршрути можна просто
редагуючи JSON, без міграцій БД.

## Поточний стан реалізації

**Готово:**
- Головний екран з повноекранною картою (MapLibre GL, OSM-тайли, 3D-будівлі, нічна тема)
- Пошук, GPS-кнопка, нижня навігація, усі 10 розділів з ТЗ
- Зупинки й маршрути — з локального JSON, без бекенду
- Обране, історія пошуку, налаштування — локальне збереження (Zustand + persist)
- Профіль — автоматично з Telegram Mini App (імʼя, юзернейм, фото), без паролів/токенів
- `<TransportSprite />` — плейсхолдер транспорту, готовий до підключення PNG Sprite Sheet
- Плавна анімація руху транспорту (інтерполяція/екстраполяція, повороти, гальмування) — на демо-даних
- PWA-іконки згенеровані (`frontend/public/icons/`)
- Автодеплой на GitHub Pages через GitHub Actions

**Потребує доопрацювання перед продакшн-релізом:**
- Наповнення JSON-даних повним переліком зупинок/маршрутів Харкова
- Підключення реального джерела координат транспорту (зараз — демо-рух,
  `useMockVehicles`); реального відкритого фіда для Харкова поки немає
- Повноцінний мультимодальний роутинг з пересадками (поточний — пряма
  відстань між точками)
- Push-повідомлення (потребують або сервера, або Telegram Bot API — окрема задача)

## Дизайн-токени

Кольори: `forest` (темно-зелений, основний), `gold` (золотий, акцент), `mint`
(світло-зелений), `graphite` (текст/темні поверхні). Стиль — glassmorphism,
великі скруглення (`rounded-xl2`/`rounded-xl3`), плавні transition. Див.
`frontend/tailwind.config.js`.
